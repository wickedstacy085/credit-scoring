# Данные

**Default of Credit Card Clients** (Yeh, I.-C., Lien, C. 2009) — 30 000 держателей кредитных карт тайваньского
банка, апрель–сентябрь 2005: лимит, пол, образование, семейное положение, возраст, статус платежей, суммы счетов
и платежей за 6 месяцев и факт дефолта в следующем месяце (22,1%).

- Источник: UCI Machine Learning Repository, https://doi.org/10.24432/C55S3H
- Лицензия: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- `credit_default.parquet` — исходный `.xls` без изменений, переведённый в parquet.

| Поле | Описание |
|---|---|
| LIMIT_BAL | кредитный лимит, NT$ |
| SEX, EDUCATION, MARRIAGE, AGE | пол, образование, семейное положение, возраст |
| PAY_0, PAY_2…PAY_6 | статус платежа в сентябре…апреле: −2/−1/0 — без просрочки, 1–8 — месяцев просрочки |
| BILL_AMT1…6 | сумма счёта за сентябрь…апрель |
| PAY_AMT1…6 | сумма платежа за сентябрь…апрель |
| default payment next month | дефолт в октябре (1/0) |

Особенности: в EDUCATION есть недокументированные коды 0, 5, 6, в MARRIAGE — 0; в анализе они объединены в «other».
