# Кредитный скоринг: вероятность дефолта по кредитным картам

**Страница проекта:** https://wickedstacy085.github.io/credit-scoring

Скоринговая карта PD по классической банковской схеме на открытых данных UCI (30 000 держателей кредитных
карт, дефолт 22,1%).

**Результат.** Карта из 12 признаков: Gini 0,52 на отложенной выборке (0,54 на обучающей), PSI 0,002.
Градиентный бустинг лучше лишь на 0,03 Gini. Оптимальный порог одобряет 75% клиентов и снижает долю
дефолтов с 22% до 13%.

| Шаг | Что сделано |
|---|---|
| Признаки | поведенческие: макс. просрочка и месяцы с просрочкой за 6 мес., загрузка лимита, доля оплаченного счёта |
| Биннинг и WoE | вручную: квантили → слияние до ≥ 5% в бине, монотонности и ≤ 6 бинов; WoE со сглаживанием |
| Отбор | IV ≥ 0,02, \|ρ\| < 0,6 между WoE; пол и семейное положение исключены |
| Модель | логит на WoE, пошаговое исключение по знаку и p-value |
| Карта баллов | 600 баллов при шансах 50:1, PDO = 20 |
| Валидация | Gini, KS, калибровка по децилям, PSI; бенчмарк — HistGradientBoosting |
| Решение | порог одобрения по прибыли при допущениях LGD 45%, маржа 15% |

## Структура

```
data/            данные UCI и описание полей
src/scoring/     data · woe · model · scorecard · metrics
tests/           17 тестов: формула WoE, монотонность, знаки, шкала баллов, метрики, экономика порога
index.qmd        страница проекта (Quarto), все числа считаются из кода
```

## Как воспроизвести

```bash
pip install -r requirements.txt
pytest
quarto render
```
